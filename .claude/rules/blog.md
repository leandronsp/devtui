# Blog Conventions

## Posts

- Files in `posts/` named `YYYY-MM-DD-slug.md`
- YAML frontmatter required: `title`, `date`, `description`
- Filename becomes the URL slug (e.g. `posts/2026-03-29-clean-code.md` → `blog/2026-03-29-clean-code.html`)

## Build

- `make blog.build` converts all posts to HTML
- `make blog.serve` builds and serves on localhost:8000
- `make blog.clean` removes the `blog/` output directory
- `blog/` is gitignored. Never commit generated HTML.

## Templates

- `templates/article.html` — pandoc template using `$title$`, `$date$`, `$body$`
- `templates/index_header.html` — static HTML header for index page
- Index generated by Makefile shell loop reading frontmatter from posts

## Styling

- Single `style.css` with CSS custom properties for theming
- Dark theme (default): `:root` variables
- Light theme (solarized): `[data-theme="light"]` override
- Syntax highlighting: breezedark (dark) and solarized (light) via CSS classes
- Toggle button persists theme choice in localStorage

## Code Blocks

- pandoc auto-detects language from fence marker (```rust, ```elixir, etc.)
- 140+ languages supported via skylighting (nasm, fasm for assembly)
- Highlight colors defined in `style.css` for both themes
